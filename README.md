# otfk-agent-skills – інструментарій викладача ОТФК для ШІ-агентів

Набір правил (скілів), еталонів і скриптів, з якими ШІ-агент (Claude Code, Claude Desktop, OpenAI Codex, Cursor, GitHub Copilot та інші, що читають `AGENTS.md` і Agent Skills) робить рутинну роботу викладача ВСП «Одеський технічний фаховий коледж ОНТУ» у єдиному форматі коледжу:

| Що вміє | Скіл |
|---|---|
| Створити або привести до еталону 2026-2027 **робочу програму** дисципліни чи практики (.docx) | `skills/robocha-programa-otfk/` |
| Згенерувати **лекцію** (.docx) і **презентацію-супровід** (.pptx) за темою з РП | `skills/lekcii-prezentacii-otfk/` |
| Згенерувати методичку **лабораторної / практичної** з трьома рівнями завдань і справжніми знімками IDE | `skills/laboratorni-roboty-otfk/` |
| Створити і вести курс **Google Classroom** за РП: теми, матеріали, завдання, бали, дедлайни | `skills/google-classroom-otfk/` + `_classroom/` |
| **Вивантажити і перевірити роботи студентів**: рівень, рекомендована оцінка, ознаки ШІ, списування, захист від вставлених промптів, HTML-сторінка результатів | `skills/perevirka-robit-otfk/` + `_classroom/` |

Усі матеріали генеруються українською, за свіжою робочою програмою, з обов'язковою самоперевіркою і перевіркою критиками (окремими субагентами).

## Структура репозиторію

```
AGENTS.md, CLAUDE.md      загальні правила для агента (ідентичні файли)
skills/<назва>/SKILL.md   п'ять скілів у форматі Agent Skills
templates/                Пример РП.docx – еталон РП; приклад РП з курсовою роботою
_classroom/               скрипти Google Classroom / Drive, шаблон HTML-звіту, приклади планів курсів
_context/                 переносима пам'ять агента: MEMORY.md, PROJECT_MAP.md (шаблони)
install/                  скрипти підключення скілів до агентів
```

## Швидкий старт

### 1. Зробіть робочу папку

Рекомендовано: клонувати репозиторій **як робочу папку** і покласти папки дисциплін усередину, поруч із `_classroom/`:

```
ОТФК Робота/                      ← клон цього репозиторію
├── AGENTS.md, CLAUDE.md, skills/, templates/, _classroom/, _context/
├── ООП РП/
│   ├── Робочі програми та силабуси/Робоча програма ООП РП 2026-2027.docx
│   ├── Лекції 2026/   Презентації 2026/   Лабораторні 2026/
│   └── Відомості та оцінки/
├── ТІК/ …
└── _labshots/                    ← тимчасові файли агента
```

Ваші папки дисциплін у git не потрапляють (`.gitignore` виключає все, крім файлів інструментарію), тож `git pull` оновлює лише правила і скрипти. Папка може лежати в OneDrive чи Google Drive – тоді один `token.json` працює на всіх ваших комп'ютерах.

Коренем робочої папки агент вважає папку, де лежить `AGENTS.md`/`CLAUDE.md`, і не виходить вище за неї – тож кілька таких папок (робоча, тестова) можуть лежати одна в одній без плутанини.

Альтернатива: клонувати репозиторій підпапкою вже існуючої робочої папки і задати змінну середовища `OTFK_ROOT=<шлях до робочої папки>` – від неї рахуються шляхи до файлів у планах Classroom.

### 2. Підключіть скіли до свого агента

Скіли – звичайні папки з `SKILL.md`. Агент сам підхоплює їх із стандартної папки:

| Агент | Папка проєкту | Папка користувача |
|---|---|---|
| Claude Code / Claude Desktop | `.claude/skills/` | `~/.claude/skills/` |
| OpenAI Codex | `.agents/skills/` | `~/.agents/skills/` |

Скрипти роблять це за вас (копіюють `skills/*` у папки проєкту та користувача для обох агентів):

```
# Windows (PowerShell), з кореня репозиторію
.\install\install-skills.ps1

# macOS / Linux
./install/install-skills.sh
```

Для інших агентів скопіюйте `skills/*` туди, де ваш агент шукає Agent Skills, або просто попросіть його прочитати потрібний `SKILL.md`. У веб-версії Claude.ai скіли додаються через Налаштування → Skills (завантажити папку скіла).

### 3. Google Classroom (за потреби)

```
cd _classroom
pip install -r requirements.txt
python classroom_auth.py          # вхід під корпоративним акаунтом коледжу
python classroom_ls.py            # ваші курси та їхні id
```

Разове налаштування Google Cloud (OAuth client), авторизація без браузера, формат плану курсу і правила заливки – у `_classroom/README.md`. Приклади планів реальних курсів – у `_classroom/plans/examples/`.

Файли `credentials.json` і `token.json` – ключі до вашого акаунта. Вони створюються локально і виключені з git. Не копіюйте їх у спільні папки й не комітьте.

### 4. Працюйте

Відкрийте робочу папку в агенті і просіть звичайною мовою, наприклад:

- «Зроби робочу програму з ТІК для 4КБ-04 за цим старим файлом»
- «Згенеруй лекцію 7 з ООП РП і презентацію до неї»
- «Лабораторна 5 з ООП КГ»
- «Залий курс УІТП КГ у Classroom за планом»
- «Вивантаж і перевір здачі 3КГ-11 з ООП та УІТП»

Агент сам прочитає `AGENTS.md`/`CLAUDE.md`, потрібний `SKILL.md`, вашу РП і зробить документ, а потім перевірить його (рендер, запуск коду, чек-лист, критики). Усе, що вимагає рішення викладача (тема лабораторної, шкала, спірні оцінки), агент запитає або залишить вам.

## Що потрібно на комп'ютері

- Python 3.11+ і `pip install -r _classroom/requirements.txt` (бібліотеки для Classroom, docx/pptx/xlsx, PDF, графіків).
- LibreOffice (`soffice`) – рендер .docx/.pptx у PDF для перевірки; Word/PowerPoint теж підходять, якщо агент має доступ до комп'ютера.
- IDE студентів (PyCharm / IntelliJ IDEA / Rider / VS Code) – для справжніх знімків екрана в лабораторних.
- Для перевірки робіт: `pandoc`, `pdftoppm` (poppler), 7-Zip/`py7zr` – опційно.

## Для авторів скілів

- Правила проєкту редагувати одночасно в `AGENTS.md` і `CLAUDE.md`; після правок `cmp -s AGENTS.md CLAUDE.md` має мовчати.
- Кожен `SKILL.md` самодостатній: структура документа, типографіка, порядок роботи, чек-лист самоперевірки і розділ «Проверка критиками». Мова скілів і всієї документації – українська; результати теж завжди українські.
- Нічого персонального: у репозиторії не повинно бути прізвищ студентів, оцінок, вивантажених робіт, `token.json`, `credentials.json`, кешів Drive. Папки `Перевірка …/`, `_classroom/reviews/`, `_classroom/plans/*.json` (крім `examples/`) виключені `.gitignore`.
