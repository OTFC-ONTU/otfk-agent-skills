# Приклади планів курсів

Плани реальних курсів ОТФК 2026-2027, залиті скриптом `classroom_sync.py`. Формат описано в `../../README.md` («Формат плану») і в `skills/google-classroom-otfk/SKILL.md`.

| Файл | Дисципліна | Курс / шкала |
|---|---|---|
| `oop-rp-2026.json` | ООП (Java), група РП, з курсовою роботою | 3 курс, 5 балів |
| `oop-kg-2026.json` | ООП (Python), група КГ | 3 курс, 5 балів |
| `uitp-kg-2026.json` | Основи управління ІТ-проєктами, група КГ | 3 курс, 5 балів |
| `tik-kb-2026.json` | Теорія інформації та кодування, група КБ | 4 курс, 5 балів |
| `nopzf-kb06-2026.json` | Навчальна ознайомча практика за фахом, 2КБ-06 | 2 курс, 12 балів |

Щоб використати: скопіюйте файл у `../` (папка `plans/`), поставте свій `course.id` (з `python classroom_ls.py`), свої назви, викладача, дедлайни і шляхи до файлів. `course.id` у прикладах належать курсам автора – для вас вони не спрацюють.
